# Sistema Manual de Contenção Animal
  

## Objetivo

- Disponibilizar um ambiente digital com informações confiáveis sobre técnicas de contenção de animais, auxiliando estudantes e profissionais da Medicina Veterinária durante seus estudos.


# Usuários
- Estudantes de Medicina Veterinária
- Professores
- Orientadores
- Médicos Veterinários
- Pesquisadores


# Problemas Identificados
- Conteúdos sobre contenção animal encontram-se dispersos em diferentes fontes.
- Muitos materiais possuem navegação pouco intuitiva.
- Dificuldade em encontrar rapidamente informações específicas de cada espécie.
- Poucos materiais apresentam conteúdo organizado juntamente com imagens e vídeos.


# Requisitos Funcionais
São as funcionalidades que o site deve oferecer.

- RF01 - O sistema deve permitir visualizar informações de diferentes grupos de animais.
- RF02 - O sistema deve exibir descrição da espécie selecionada.
- RF03 - O sistema deve apresentar imagens ilustrativas para auxiliar o aprendizado.
- RF04 - O sistema deve disponibilizar vídeos educativos quando disponíveis.
- RF05 - O sistema deve possuir menu para navegação entre os grupos de animais.
- RF06 - O sistema deve permitir acesso ao manual sem necessidade de autenticação.
- RF07 - O sistema deve apresentar informações organizadas por categoria (Mamíferos, Aves, Répteis, etc.).
- RF08 - O sistema deve possuir página com informações da equipe responsável pelo projeto.


# Requisitos Não Funcionais
Características técnicas do projeto.

- RNF01 - O site deve ser responsivo para dispositivos móveis, tablets e desktops.
- RNF02 - O tempo de carregamento das páginas deve ser inferior a 3 segundos em conexão comum.
- RNF03 - O projeto deve utilizar HTML5 semântico.
- RNF04 - O projeto deve utilizar CSS organizado em arquivos separados por responsabilidade.
- RNF05 - O JavaScript deve ser modularizado sempre que possível.
- RNF06 - O código deve seguir boas práticas de organização e nomenclatura.
- RNF07 - O site deve funcionar nos principais navegadores modernos.
- RNF08 - As imagens devem ser otimizadas para reduzir o tempo de carregamento.


# Regras de Negócio
Mesmo sendo um site informativo, existem regras.

- RN01 - Cada espécie pertence a apenas um grupo de animais.
- RN02 - As informações apresentadas devem possuir caráter exclusivamente educativo.
- RN03 - Os vídeos apresentados devem estar relacionados à espécie selecionada.
- RN04 - Cada espécie deve possuir pelo menos uma descrição.
- RN05 - O usuário pode navegar livremente entre todas as páginas.
